# 📂 File Organizer Pro

Automação em Python para organização inteligente de arquivos baseada em extensões.

## 🚀 Funcionalidades
- Separa arquivos por categorias (Imagens, Documentos, etc).
- Cria pastas automaticamente.
- Gera um relatório `json` detalhando cada movimentação.
- Interface simples via Linha de Comando (CLI).

## 🛠️ Tecnologias
- **Python 3.x**
- Biblioteca `os` (Manipulação de caminhos)
- Biblioteca `shutil` (Movimentação de arquivos)

## 📦 Como Usar
1. Clone o repositório: 
2. Execute: `python organizer.py`
3. Insira o caminho da pasta que deseja limpar.
